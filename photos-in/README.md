# Fotografii pentru lucrări

1. Fă un folder cu id-ul lucrării din `src/data/projects.ts` (de exemplu `terasa-fotovoltaica/`, `bar-stools/`, `firepit/`).
2. Pune în el pozele originale (JPG / PNG / WebP), numite în ordinea dorită: `01-....jpg`, `02-....jpg`.
3. Opțional, `alt.json` cu descrieri pentru fiecare poză (ro / en). Cheia este numele fișierului fără extensie.
4. Rulează `npm run photos`. Prima poză devine imaginea lucrării pe card, iar toate apar în galeria lucrării.
